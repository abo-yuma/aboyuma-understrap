## ABO YUMA - Personal Blog WordPress Theme
A custom WordPress theme built for Yuma's personal blog.
This theme is based on the Understrap Starter Theme.

## Theme Integrated Plugins
This theme includes 3 custom Plugins integrated into the theme:
- News CRUD
- Gallery CRUD
- Amway Product CRUD
- Amway Shop CRUD
